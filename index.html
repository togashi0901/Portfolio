制作物

AIケア記録要約システム

ケアマネジャーの記録要約業務を、AIで大幅に効率化

Overview
ケアマネジャーが行う「利用者の介護記録をまとめ、ご家族へ伝える」業務を支援するシステム。日々の介護記録やケアプランをもとに、全体の総括・状態の推移・項目別評価（健康管理／医療処置／食事／排泄／入浴／睡眠／アクティビティ）を自動生成し、家族向けの報告書まで出力できます。
Tech Stack
Angular Express MySQL OpenAI API GitHub Copilot Gemini
Role / Period
450時間の長期インターン ／ インターン生2名（環境構築・テストデータ作成は企業様、メイン開発は一人で担当）
Highlights
  • 業務量の大幅削減 ケアマネジャーが利用者一人につき膨大な情報を手作業でまとめる工程をAIに任せることで、作業時間を大きく短縮した。
  • AIの誤情報を防ぐ精度設計 要約が不正確だと現場の混乱を招くため、AIに渡す前のデータ整形・プロンプトによる厳密なルール付け・出力制御に注力し、「事実に基づいた情報のみ抽出」する仕組みを構築した。

社員登録Webアプリケーション

人事担当向け・社員情報管理システム

Overview
ウォーターフォール型開発の一連の流れを体験することを目的に、人事担当向けの社員情報管理アプリを開発。「社員一覧」「社員新規登録」「社員情報更新」「社員No変更」の4画面・3機能を実装した。
Tech Stack
React C# MySQL
Role / Period
150時間（約1ヶ月半）の長期インターン ／ 株式会社ミロク情報サービス様での実習
担当工程：要件定義 → 外部設計 → プログラミング → 単体テスト仕様書 → 単体テスト（全工程を一人で完遂）
Highlights
  • 顧客視点を持ったものづくり 架空とはいえ顧客を意識し、要件を必ず満たすこと、スケジュールを守ることを徹底。個人開発では経験できなかった「制約のあるものづくり」を学んだ。
  • ウォーターフォール型開発の実践 外部設計書を正確に読み取り、ブレなく実装することの重要性を体感。単体テストでは「曖昧な記述や漏れを作らない」ことに注力した。
  • 報告・質問の力が身についた わからないことを明確にして質問するスキル、進捗をこまめに共有する習慣がついた。

狐集会

「同じアバターコンセプト」をテーマにした、メタバース上の交流イベント

Overview
同じコンセプト（狐系アバター）を持つユーザー同士の交流の場として企画した、VRChat上のイベント。「夜桜」をテーマにしたオリジナルワールドを制作し、写真撮影と交流を楽しめる空間を作り上げた。
Tech Stack
Unity 2022.3.22f1 VRChat SDK VRChat
Role
企画・運営・集客・ワールド制作・宣伝ポスター作成 ─ すべて個人で実施（準備期間：約1ヶ月）
Highlights
  • アバター文化に寄り添うワールドデザイン 集まる人のアバターコンセプトが決まっているため、どの雰囲気のアバターにも合う夜桜の世界観を意識。空間サイズも「狭すぎず・広すぎず」、交流と撮影が両立できるバランスを追求した。
  • パフォーマンス最適化 多人数の同時参加を想定し、ワールドの軽量化に注力。安定した体験を提供できるよう調整した。
  • 「孤立を生まない」動線設計 「話の輪に入れない」状態を防ぐため、参加者の動線を設計：① 入室 → 大きな桜の木の前へ自然に誘導　② 写真撮影＋運営（自分）との会話　③ 既に集まっている人たちへスムーズに案内、という流れで初参加者も馴染めるよう配慮。
